# 07 · 代码结构与规模规划

> 本文档是**规模硬性约束**的落地方案：Go 代码文件清单、每文件行数预算、
> 测试计划与验证命令。实现阶段必须按此规划执行，并最终通过验证脚本确认。

---

## 1. 硬性验收标准

| 约束 | 要求 | 目标值 | 判定方式 |
| --- | --- | --- | --- |
| 非测试 Go 行数 | **2000 < 行数 < 2200**（即 2001~2199） | ≈ 2060 | 脚本统计 |
| Go 代码文件数 | **20 < 文件数 < 25**（即 21~24） | 22 | 脚本统计 |
| 测试代码 | 不参与上述统计（`*_test.go` 除外） | 独立统计 | 脚本排除 |
| 前端 | 提供简单界面 | 3 个静态文件 | 人工/HTTP 验证 |
| 质量 | `go build` / `go vet` / `go test` 全绿 | — | 命令验证 |

**统计口径**：仅统计 `cmd/` 与 `internal/` 下的 `*.go`（排除 `*_test.go`）；
`web/`、`docs/`、`migrations/`、`go.mod`、`Makefile` 均不计入。

```bash
# 非测试 Go 文件数
find cmd internal -name '*.go' ! -name '*_test.go' | wc -l        # 期望 22

# 非测试 Go 行数
find cmd internal -name '*.go' ! -name '*_test.go' | xargs wc -l | tail -1   # 期望 ≈ 2060
```

### 2.1 行数预算区间与调整策略

- 目标是 **≈2060 行**，处于 2001~2199 安全区（上下各留约 40~140 行余量）；
- 若最终统计 **< 2001 行**：优先补充独立小工具函数（如存储层 `SafeFilename`、
  领域层枚举辅助、service 层 `SummarizeError`），而非注释填充；
- 若最终统计 **> 2199 行**：合并小型辅助函数（如 `middleware.go` 并入 `router.go`、
  `event_repo.go` 并入 `task_repo.go`），文件数仍保持在 21~24；
- 行数判定以**最终统计脚本输出**为准，不依赖人工估算。


### 5.2 手工/端到端验证

| # | 步骤 | 期望 |
| --- | --- | --- |
| 1 | `go run ./cmd/api` + `go run ./cmd/worker` | 双进程启动，日志无错误 |
| 2 | 上传合法 `report.txt` | 返回 201 + task_id；轮询后终态 SUCCEEDED，事件含 4 阶段 |
| 3 | 上传伪造扩展名文件（文本内容带 NUL 的 `.txt`） | 终态 FAILED，错误码含校验原因，事件轨迹完整 |

| 5 | 关闭扫描服务后上传 | 任务自动重试（事件含 RETRYING），重启扫描服务后最终成功 |

## 6. 实现顺序建议

1. `internal/domain`（实体 + 状态机）→ 先写状态机测试；
2. `internal/config` + `internal/migrate` + `migrations/*.sql`；
3. `internal/storage` + `internal/repository`（含乐观锁）；
4. `internal/service`（validator → extractor → scanner → retry → pipeline）；
5. `internal/worker`（worker + processor）；
6. `internal/api` + `cmd/api` + `cmd/worker`；
7. `web/` 前端三件套；
8. 补充 `_test.go` 全量测试 → `make verify` 全绿 → 规模统计达标。

## 7. 风险与预案

| 风险 | 预案 |
| --- | --- |
| 行数低于 2001 | 补充独立工具函数/更完整的分支处理（见 2.1） |
| 行数高于 2199 | 合并小文件/简化重复分支（见 2.1） |
| 文件数低于 21 | 拆分 `handlers.go`（上传/查询/回调三个文件） |
| 文件数高于 24 | 合并 `middleware.go`/`storage.go` 接口与实现 |
| 现代 SQLite 驱动体积争议 | 保持 `modernc.org/sqlite`，如需可换 `mattn/go-sqlite3`（文档不变） |
